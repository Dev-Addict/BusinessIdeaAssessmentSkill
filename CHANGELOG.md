# Changelog

All notable changes to this project are documented here.

## 0.3.0 — 2026-10-20

- Made a numerical success-probability range mandatory for every assessed
  offer and strategy, including pre-revenue concepts with no traction evidence.
- Added a neutral estimation method covering reference classes, explicit
  assumptions, contrary evidence, confidence, dependencies, and bias checks.
- Added success-matrix schema requirements, review checks, behavioural cases,
  and structural validation for probability bounds.

## 0.2.1 — 2026-10-19

- Added the Skills CLI installation and discovery commands to `README.md`.
- Added a visible release-version badge.

## 0.2.0 — 2026-10-19

- Added documented personal and project installs for Codex, Claude Code,
  OpenCode, and Pi.
- Added a shared `.agents/skills/` installation for compatible agents.
- Added invocation, reload, capability, and generic-agent fallback guidance.

## 0.1.0 — 2026-10-19

- Initial public release.
- Added full-cycle market and feasibility assessment workflow.
- Added safe autonomous follow-on selection and execution guidance.
- Added evidence, model, integration, and clean-room review gates.
- Added user checkpoint and external-action boundaries.
- Added repository and generated-assessment validators.
